# BGM Extractor 产品路线图

## 产品愿景

打造最简单易用的 AI 音频分离工具，让每个人都能轻松提取歌曲中的背景音乐和人声。

---

## 当前版本 v0.1.0 (已完成)

### 核心功能
- [x] 音频文件导入（支持 MP3, WAV, FLAC, M4A, OGG, AAC）
- [x] AI 音频分离（基于 Demucs）
- [x] 人声/伴奏分离
- [x] 实时进度显示
- [x] 多模型支持（htdemucs, htdemucs_ft, mdx_extra）
- [x] MPS GPU 加速（Apple Silicon）
- [x] 独立打包（无需 Python 环境）

### 技术栈
- 前端：Vue 3 + TypeScript + Vite
- 后端：Tauri 2 (Rust)
- AI 引擎：Demucs (PyTorch)
- 打包：PyInstaller
